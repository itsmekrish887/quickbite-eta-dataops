# Prompt 01 — Initial Dashboard

Build an internal operations dashboard for a food-delivery company called QuickBite.

The dashboard supports an AI Data Operations Manager responsible for an ML model that predicts food-delivery ETA.

The dashboard should show:

- ETA model performance
- data pipeline health
- annotation and QA status
- batch/vendor status
- emerging operational issues

Use synthetic data.

Include four cities:
- Mumbai
- Bengaluru
- Hyderabad
- Delhi

Use a clean enterprise dashboard layout.

Focus on operational clarity, not marketing-style visuals.

The dashboard should help an operator quickly answer:
1. Is the ETA model healthy?
2. Is the data pipeline healthy?
3. Are there any major operational issues?
